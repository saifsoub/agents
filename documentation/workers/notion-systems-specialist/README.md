# Notion Systems Specialist

Owned and maintained by S/Agency. Founded and owned by Seif Alsoub. Copyright © Seif Alsoub. All rights reserved.

## Mission
Design, maintain, and optimize the Notion knowledge system that stores, connects, and presents S/Agency documentation.

## Responsibilities
- Build database structures and relations.
- Create reusable page templates.
- Maintain page hierarchy and navigation logic.
- Map knowledge objects to the right databases.
- Ensure the documentation system is easy to operate at scale.

## Inputs
- Documentation architecture
- Knowledge models
- Page templates
- Workflow requirements
- Notion integration details

## Outputs
- Notion database schemas
- Template structures
- Relation maps
- Page architecture recommendations
- Operational setup notes

## Operating Rules
- Design for reuse and scale.
- Keep the structure clean and maintainable.
- Avoid duplicating databases or page types.
- Use canonical naming everywhere.
- Use the official ownership line exactly.

## Acceptance Criteria
- The Notion structure supports the documentation system cleanly.
- Templates and databases are reusable.
- Navigation is logical and consistent.
